# Evidence record skill

Rule 11: raw evaluation data stays outside the repository. Each note that cites an evaluation commits a compact per-seed record with the commit, suite, model, and command needed to rerun any seed.

## Running

From the repository root:

```bash
uv run --project nethack-agent python3 _agents/skills/evidence-record/record.py \
  REPORT_JSON \
  --commit SHA \
  --command "CMD" \
  [--classes CLASSES_JSON] \
  --output OUT_JSON
```

- `REPORT_JSON`: Input evaluation report generated by `nethack-agent eval run`.
- `--commit`: Git SHA at which the evaluation was run.
- `--command`: Base rerun command used for the evaluation.
- `--classes`: (Optional) Path to a JSON file mapping seed (string or integer) to a concise failure class label.
- `--output`: Destination path for the compact evidence record (e.g. `docs/notes/evidence/<note-number>/<report-stem>.json`).

## Output schema and meaning

The output JSON contains:

- `header`:
  - `suite_id`: Name / ID of the evaluation suite.
  - `suite_sha256`: SHA-256 digest of the evaluation suite definition file (if present in the report).
  - `report_file`: Base filename of the original report.
  - `started_at`: Timestamp when evaluation started.
  - `model`: Model identifier (e.g. `scripted-development`).
  - `policy_version`: Policy version name.
  - `knowledge_version`: Knowledge bundle version / digest.
  - `max_episode_steps`: Episode step cap configured for runs.
  - `commit`: Git commit SHA for reproducibility.
  - `command`: Full rerun command.
  - `rerun_hint`: Suggested rerun command format appending `--seeds <seed>`.
- `rows`: List of per-seed run summaries sorted deterministically by `(case_id, seed)`:
  - `case_id`: Test case identifier within the suite.
  - `seed`: Random seed.
  - `outcome`: Run outcome (`death`, `objective_complete`, `truncated`, etc.).
  - `steps`: Action step count.
  - `game_turns`: In-game NetHack turn counter.
  - `death_cause`: Cause of death (or `null` if survived/succeeded).
  - `hunger_at_death`: Hunger status when episode ended in death.
  - `max_depth`: Maximum dungeon level depth reached.
  - `final_level`: Level where the run ended formatted as `"<dungeon_number>:<dungeon_level>"`.
  - `failure_class`: Failure category string from `--classes`, or `null`.
